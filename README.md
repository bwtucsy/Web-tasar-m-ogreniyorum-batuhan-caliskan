# 🎮 GAMEZONE – Oyun Tanıtım Sitesi

GAMEZONE, oyun severler için hazırlanmış modern ve şık tasarıma sahip bir oyun tanıtım web sitesidir. Kullanıcıların popüler oyunları inceleyebilmesi ve oyunlar hakkında bilgi alabilmesi amacıyla geliştirilmiştir.

## 🚀 Kullanılan Teknolojiler

- **HTML5:** Web sitesinin temel yapısı oluşturuldu.
- **CSS3:** Renkler, tasarım, kart yapıları ve sayfa düzeni oluşturuldu.
- **JavaScript:** Butonlara işlevsellik kazandırıldı.

## 🛠️ Projede Neler Yapıldı?

- Modern ve koyu temalı bir web arayüzü tasarlandı.
- GAMEZONE başlıklı bir navigasyon menüsü oluşturuldu.
- Ana sayfa için tanıtım alanı hazırlandı.
- Popüler oyunlar bölümü oluşturuldu.
- GTA V, Valorant ve Forza Horizon 5 oyunları eklendi.
- Oyunlar için görsel, başlık ve açıklama alanları hazırlandı.
- Oyun kartlarına detay butonları eklendi.
- JavaScript kullanılarak butonlara tıklandığında uyarı mesajı gösterilmesi sağlandı.
- Hakkımızda ve İletişim bölümleri oluşturuldu.

## 🎨 Tasarım Özellikleri

- Koyu arka plan tasarımı
- Mor ve mavi tonları
- Yuvarlatılmış oyun kartları
- Fare ile üzerine gelindiğinde animasyonlu kart efektleri
- Basit ve kullanıcı dostu menü


## Requirements(HOW TO USE)

1. Projeyi bilgisayarınıza indirin.
2. GAMEZONE klasörünü açın.
3. `index.html` dosyasını tarayıcıda çalıştırın.

## 📌 Projenin Amacı

Bu proje, HTML, CSS ve JavaScript kullanarak temel web geliştirme becerilerini öğrenmek ve uygulamak amacıyla hazırlanmıştır.
